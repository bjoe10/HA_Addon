# Hausakku-Planer

Plant Laden, Halten und Versorgen eines Heimspeichers nach dynamischen Strompreisen
(Tibber-Viertelstundenpreise, PV- und Verbrauchsprognose, Mehrtagessicht), mit Weboberfläche in der HA-Seitenleiste.

**Status:** in Entwicklung. Standardstufe `observe` schreibt nichts in Home Assistant; das Add-on schaltet selbst keine Geräte.
Details: [DOCS.md](DOCS.md), Architektur: [dev/docs/ARCHITECTURE.md](dev/docs/ARCHITECTURE.md). Tests: `dev/run_tests.sh`. Lizenz: MIT.

Die Berechnung ist eine Simulation; es gibt keine Garantie für Ersparnisse. Nutzung auf eigene Verantwortung.
